# NammaCityFix – Civic Issue Management System

## Overview
NammaCityFix is a web-based platform that allows citizens to report and track civic issues such as potholes, garbage, and water leaks. It uses image uploads and location-based tagging to improve transparency and faster resolution.

## Features
- Report issues with images and location
- Real-time complaint tracking
- Department-wise dashboard for issue management
- Automatic issue categorization using CNN

## Tech Stack
- Backend: Python, Flask  
- Frontend: HTML, CSS, JavaScript  
- Machine Learning: CNN  
- Database: SQLite  

## How to Run
1. Clone the repository  
2. Install dependencies: `pip install -r requirements.txt`  
3. Run the application: `python app.py`  
4. Open in browser: `http://localhost:5000`
